A FEW USEFUL BOUNDARIES

Simple tools.
Clear expectations.

01

Check the processing label

Ten tools run entirely in your browser, including Encoder, Regex, Signature, and CIDR. Other tools use this Python server; Hash explicitly offers both modes. The processing label always tells you where content goes.

02

Keep the original

Tools show transformations separately. Review settings and results before sharing. JSON collapse changes the view, not your document. Sanitizer replaces only the values or patterns you select.

03

No saved history

There are no accounts or databases. Content and replacement mappings are not retained between operations. Only your light/dark theme preference is stored in this browser.

04

Work within the limits

Text inputs allow up to one million characters and 5 MiB per file. Server hashing allows 50 MiB; browser hashing allows 5 MiB. Heavy outputs and deeply nested records are bounded.

A matching hash is not a safety verdict. Encoding is not encryption. Review sanitized output for remaining sensitive information.
